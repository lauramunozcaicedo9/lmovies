## Key Features

Built a dummy movies service with Javascript that shows information of most important movies at the moment, consuming <a href="https://www.themoviedb.org/" target="_blank">Themoviedb.org API</a>. Created a multilingüal system to translate the platform in portuguese, english and spanish. Included Lazy Load and strategies to optimize the movie list rendering. Integrated local storage to save favorite movies.


## How To Use

To clone and run this application, you'll need [Git](https://git-scm.com). From your command line:

```bash
# Clone this repository
$ git clone https://github.com/lauramunozcaiced/lmovies.git

$ cd lmovies

```

You can use the page to find your favorites movies in this link:
[L-MOVIES Page](https://lauramunozcaiced.github.io/lmovies/)
